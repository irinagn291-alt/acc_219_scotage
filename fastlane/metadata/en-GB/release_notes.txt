The rate face shows lots that bill this month. Set a Scot pin for the month you can bear. Add a lot with Lot name, Amount, Period and Next charge. Tap the aimed lot to file it quit. The needle falls and cancel-savings rise. A miss cools the wrong arc and leaves the hand.

Insights lists Quit marks, Cooled misses, Leftover overrun and Mystery charges. Settings holds Currency, Scot pin, Local reminder, Contact, How Aim then Quit works, Re-run onboarding and Reset all data. Currency stays on this device. There is no bank login.
